Steam Frame 充电协议插件 0.7.0

安装与设置
手动安装时，可在 Framey App 中选择 Add plugin 并导入整个 ZIP。Framey App 安装成功后会重启运行中的 SteamVR。
打开 Framey → 充电协议。慢充弹窗、慢充提示音、协议浮层、完整名称、淡出、停止充电浮层和声音都有独立开关。浮层可在九个位置之间选择，时长可选 3、5、8 秒。设置自动保存。

显示与声音
USB PD 和 USB PD PPS 以实际协商状态为准。协议浮层默认附上本次协商的瓦数，例如 USB PD · 39 W。详情实时显示协议、协商电压电流和电池净功率，电池净功率的正负值分别表示充电和放电。可在菜单里关闭浮层上的瓦数。
「蓝牙电量来源」默认使用系统蓝牙，只显示系统已经上报的已连接蓝牙音频设备电量。连接小米 Air 4 SE 后，可手动选择分项模式读取左耳、右耳和充电盒。分项模式保留本次运行已读到的数值，并标注「上次读数」。耳机读数只在详情打开时刷新。
浮层从出现时起计时，淡出计入总时长。插头断开或电池由充电转为持续不充电时，可分别启用「停止充电」浮层和一声双音提示。暂停充电后过一段时间再拔线，也会提醒。如果两项均开启，头显待机时会等浮层出现再播放提示音。
慢充静音只处理 Steam 客户端慢充弹窗对应的打开和关闭音效。该功能依赖 Steam 客户端的内部界面，升级后需重新确认兼容性。游戏、低电量和其他系统音效照常使用 Steam 的设置。

语言
内置简体中文、繁体中文和英文。默认跟随 Steam，其他系统语言回退到英文。菜单字符串维护在 locales.json，停止充电浮层使用对应语言的预渲染图片。USB 协议名称使用标准英文名称。

卸载
在头显 Framey 的 Settings 中停用或移除「充电协议」。
